Pregunta 1: Una WAN cubre distancias geográficas y normalmente usa infraestructura de terceros para conectar redes que están muy separadas entre sí.

Una MAN cubre un área intermedia, como una ciudad o un pueblo, conectando varias LANs dentro de esa zona. Es más rápida y tiene menor latencia que una WAN.

Pregunta 2: Orientada a conexión: antes de enviar datos se establece una conexión entre emisor y receptor: hay fase de setup, transferencia y cierre. Garantiza entrega ordenada y confiable.

No orientada a conexión: cada paquete (datagrama) se envía de forma independiente, sin necesidad de establecer una sesión previa, y puede tomar rutas distintas hasta el destino.

Pregunta 3: Una red punto a punto es aquella donde existe un enlace dedicado y directo entre exactamente dos dispositivos, sin que el medio sea compartido con otros nodos. Y se implementa cada par de dispositivos mediante un enlace físico exclusivo. No hay necesidad de protocolos de arbitraje de acceso al medio.

Pregunta 4: FDM (Frequency Division Multiplexing): el ancho de banda disponible del canal se divide en varias subbandas de frecuencia, y cada señal transmite simultáneamente pero en su propia banda de frecuencia asignada.

TDM (Time Division Multiplexing): todas las señales comparten la misma frecuencia, pero cada una transmite en turnos, ocupando ranuras de tiempo asignadas de forma rotativa. Solo una señal usa el canal en cada instante.
